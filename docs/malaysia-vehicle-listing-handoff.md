# Real vehicle listing handoff

Use vehicle-inventory-intake.csv for facts and create one photo folder per stock code. Leave a field blank when it is not confirmed; never guess ownership, accident, flood, service, warranty, or mileage-verification claims.

The listing supports 21 photos. If the car has a visible scratch, dent, repaired area, warning light, tyre issue, or upholstery defect, replace one or more of the lower-priority wheel/tyre or detail shots with honest close-ups. Disclosure is more important than completing the ideal shot list. Mask number plates and do not publish owner names, identity numbers, addresses, full VINs, or unredacted registration/service documents.

## Data conventions

- fuelType: PETROL, DIESEL, HYBRID, or ELECTRIC
- transmission: AUTOMATIC or MANUAL
- status: AVAILABLE, RESERVED, or SOLD
- publish: TRUE only after the listing has been checked
- featuresPipeSeparated: one confirmed item per separator, for example Apple CarPlay|Reverse camera|Six airbags
- photoFolder: the local folder name or a shared folder link containing only that vehicle's photographs

Upload original dealership photos. Do not copy photographs or descriptions from another dealer's listing.
